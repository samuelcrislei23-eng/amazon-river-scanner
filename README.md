# Amazon River Scanner

App Android que escaneia textos com a câmera (OCR offline, ML Kit) e monta em formato de prova:

QUESTÃO 1 / enunciado / a) b) c) d) e)

## Gerar o APK
1. Suba esta pasta para um repositório no GitHub.
2. Aba Actions > "Build APK" > Run workflow (ou só dar push).
3. Baixe o artefato `AmazonRiver-Scanner-apk` e instale o .apk.

## Como usar
- Aba Scanner: passe a câmera sobre o texto. Em modo Contínuo as linhas novas entram sozinhas (sem repetir).
- Aba Prova: texto montado, editável. Copiar, Compartilhar, Remontar.
