# Amazon River Scanner

Passe a câmera (vídeo) sobre o texto. O app lê, corta as linhas sem sentido (movimento rápido),
junta as leituras repetidas e monta no padrão de prova: QUESTÃO 1 / enunciado / a) b) c) d) e).
Tudo offline, sem chave de API.

## Gerar o APK
1. Suba esta pasta para um repositório no GitHub.
2. Aba Actions > "Build APK" > Run workflow.
3. Baixe o artefato `AmazonRiver-Scanner-apk` e instale o .apk.
